rag-contract

A question-answering service over a fixed corpus of six IETF RFCs, built as a contract rather than a pipeline: what it retrieves is measured, what it cannot support it refuses, and every answer names the index version it came from.

llm-inference-cp

A distributed control plane for LLM inference serving, written in Go. It owns membership, failure detection and routing, and stays out of the data path — it tells the gateway who to route to, never forwarding a byte itself.

  • One command induces two failures — a crash and a healthy worker misjudged dead — and no request is lost
  • Liveness is a phi-accrual suspicion score, not a fixed timeout
  • When a false positive puts two attempts on one request, first-wins adjudication discards the loser

Go · gRPC · Protobuf · phi-accrual detection
